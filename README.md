# Abdi Aziz Jama — Personal Portfolio

A responsive static portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — the complete website (styles and JavaScript are included).

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Sign in to GitHub and open your repository: https://github.com/abdiazizjama209-sketch
2. Create a new repository named **abdiazizjama209-sketch.github.io** (recommended for a personal site).
3. Upload `index.html` to the root of that repository and commit the changes.
4. Open the repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. Your website address should be:
   `https://abdiazizjama209-sketch.github.io/`

If you prefer to use an existing repository, upload `index.html` to its root, then enable Pages from **Settings → Pages**. The published URL will include the repository name.

## Personalise it
Open `index.html` in a text editor and update the About, Skills and Projects sections as your experience grows. Keep project descriptions accurate. No email address or certifications have been added because none were provided.


## Profile photo
Keep `profile.jpg` in the same folder as `index.html` when uploading to GitHub Pages.
